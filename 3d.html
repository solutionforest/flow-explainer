How it works

  1. Paste a markdown file with a Mermaid diagram, and a numbered list to explain each step.
  2. Play it one arrow at a time. The camera follows each step and the side panel explains it in plain language.
  3. Share a view-only client link, or save a PNG for your README.

Your diagram stays with you

Nothing is uploaded. Drafts stay in this browser, and a client link carries the diagram inside the link itself. The link is not encrypted, so share it like the document.

Paste your markdown

Paste a GitHub markdown file that contains a ```mermaid block (flowchart, sequenceDiagram, stateDiagram, classDiagram, erDiagram, gantt, pie, mindmap, journey, timeline, quadrantChart, gitGraph, xychart, sankey, block, architecture, C4, kanban, packet or requirementDiagram). Optional: a numbered list under the diagram becomes the explanation for each step, and - **Box name**: text adds a note to a box.
